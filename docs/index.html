Config that checks
itself. No installs.

envkit is a small command-line tool that catches missing or wrong settings in a .env file — before your app crashes because of them. It's built entirely from Node.js's own built-in tools, with nothing downloaded from the internet.

What it does
Reads a .env file, checks required settings are present and correctly typed, and lets settings reference each other (e.g. a URL built from a host and a port)
Normally needs
dotenv + dotenv-expand + zod (3 downloaded packages)
